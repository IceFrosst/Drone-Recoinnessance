      About the model

      Same flights, two receivers

      To compare fairly, both receivers fly the same predefined routes, record, and build the heat map after landing — no 180° arc, no in-air tasking, multiple flights per map. Both also run the same 5-stage filter (band · self-noise · noise-floor · hop fingerprint · convergence) the live-tasking sim uses — the clutter you see getting through is only the other control links that share a target's band and fingerprint, which no filter removes. The only difference is the receiver, so the gap below is what the receiver alone buys.
